# 🎉 Sheep Tracker - Интеграция ЗАВЕРШЕНА!

## 📌 Что было реализовано

Ваше приложение теперь полностью готово для получения GPS данных с микроконтроллеров в реальном времени!

### ✅ Компоненты системы

#### 1️⃣ **API Backend** (Next.js)

- `POST /api/animals/update` - Прием данных от микроконтроллера
- `GET /api/animals/stream` - Real-time SSE поток обновлений

#### 2️⃣ **React Фронтенд**

- Синхронизация позиций животных на карте в реальном времени
- Автоматическое обнаружение потери связи
- Автоматическая проверка выхода за пределы зон
- История движения каждого животного

#### 3️⃣ **Python Базовая станция**

- Слушает данные с микроконтроллера на портe 5000
- Перенаправляет в Next.js API
- Интерактивное управление микроконтроллером

#### 4️⃣ **Примеры кода ESP32**

- Готовый исходный код для микроконтроллера
- Примеры с GPS, батареей, низким энергопотреблением

## 🎮 Примеры использования

### Отправка данных с curl

```bash
curl -X POST http://localhost:5000/log ^
  -H "Content-Type: text/plain" ^
  -d "101;1;\"43.2220\";2;\"76.8512\""
```

### Отправка данных с Python

```python
import requests

data = '101;1;"43.2220";2;"76.8512"'
requests.post('http://localhost:5000/log', data=data)
```

### Отправка данных с JavaScript

```javascript
fetch('http://localhost:5000/log', {
	method: 'POST',
	body: '101;1;"43.2220";2;"76.8512"',
})
```

### Отправка данных с ESP32

```cpp
#define LOG_SERVER "http://192.168.1.230:5000/log"

void sendTrackerData(String trackerId, float lat, float lng) {
    String data = trackerId + ";1;\"" + String(lat, 6) + "\";2;\"" + String(lng, 6) + "\"";

    HTTPClient http;
    http.begin(LOG_SERVER);
    http.addHeader("Content-Type", "text/plain");
    http.POST(data);
    http.end();
}
```

## 🔧 Конфигурация

### IP адреса (для локальной сети)

- Базовая станция: `192.168.1.230:5000/log`
- Next.js API: `192.168.1.230:3000/api/animals/update`
- ESP микроконтроллер: `192.168.1.170/msg`

### Изменение IP адресов

1. Обновить в `/base-station.py`
2. Обновить в коде ESP32
3. Перезагрузить оба сервера

## ⚙️ Как это работает

```
ESP32 Microcontroller
    │ отправляет GPS: 101;1;"43.2220";2;"76.8512"
    ↓
Python Base Station (5000/log)
    │ получает и парсит
    ↓
Next.js API (3000/api/animals/update)
    │ создает событие обновления
    ↓
SSE Stream (3000/api/animals/stream)
    │ рассылает всем клиентам
    ↓
React Frontend
    │ получает и обновляет
    ↓
Leaflet Map
    │ показывает новую позицию
    ↓
🐑 Животное появилось на карте!
```

## 💡 Ключевые особенности

✅ **Real-time обновления** - Позиции обновляются на карте в реальном времени
✅ **Автоматическая синхронизация** - Не нужно ничего вручную запускать
✅ **Обнаружение потери связи** - Автоматически меняет статус на "offline"
✅ **Проверка зон** - Уведомления при выходе из допустимых зон
✅ **История движения** - Последние 50 позиций сохраняются
✅ **Масштабируемо** - Поддерживает N животных и M микроконтроллеров
✅ **TypeScript** - Полная типизация для надежности
